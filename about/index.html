Methodology

  1. Intent over volume. Each URL answers one job: beginner host, student project, shared vs managed cloud, a named pair, or a $0 deploy.
  2. Criteria, not scores. We do not average “speed / support / price” into a fake 9.4. You should weigh the criteria for your project.
  3. Public sources only. Product claims come from official sites. If we lack a 2026-08-28 official quote, we write “check the provider’s current pricing page” instead of a number.
  4. Name the gap. Every comparison has a “what we have not measured” section.
  5. Static-first bias (disclosed). If a page can ship as HTML, we recommend a $0 static host before a paid control panel. That matches a student budget. It is also the honest default.
